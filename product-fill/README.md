# Ручное заполнение товаров MotorSky

Подготовлено по полям темы 1.3 и старому сайту на 15 октября 2026 года. Веб-страницы содержат расхождения; точные параметры для запуска следует сверить с документацией заказчика. Тему и товары этим действием не изменял, записи автоматически не создавал.

## Внешний вид

В версии 1.5 страница товара сохраняет исходные секции и Swiper. Под названием добавлены шесть кратких параметров, винт выведен также в таблице, ниже есть навигация по опубликованным моделям. Испытания и документация видимы всегда — флажок больше не требуется. В «Товары → Настройки каталога» кнопка «Создать / дополнить пять товаров» заполняет пустые характеристики и материалы 2807–1300, 2810–1500 и 3115–900 по старым страницам, сохраняя ручные значения. Для двух других вариантов нужны исходные данные, а для шестой модели — подтверждение названия.

## Как пользоваться

1. Откройте «Товары → Добавить товар» или созданный черновик.
2. Переносите содержимое блоков «text» в одноимённые поля. Названия полей, пояснения и отметки «оставьте пустым» вставлять не нужно.
3. «Основное содержимое» — большой редактор описания, «Краткое описание» — поле отрывка. В редакторе записи можно включить скрытые панели через его настройки.
4. Сначала сохраните черновик. Проверьте изображение, характеристики, документы и предпросмотр; затем публикуйте.
5. Поля изображений, графиков и документов заполняются вашими файлами. В галерее и чертежах нажмите «Выбрать / загрузить картинки», выберите файлы и расставьте миниатюры перетаскиванием или стрелками. ID вручную вводить не нужно. Указания о ручном вводе ID в старых памятках моделей больше не применяются.

В пяти моделях чек-листа нет 3120–500 KV. Поэтому собраны пять карточек по чек-листу и отдельно справочная шестая карточка со старого сайта. Для 3115–400 и 3115–1300 на проверенных страницах старого сайта характеристик не найдено: не копируйте им данные 3115–900.

## Что одинаково заполняется у подтверждённых четырёх моделей

Следующие данные приведены на старых страницах и в исходной вёрстке проекта; используйте этот блок для 2807–1300, 2810–1500, 3115–900 и, если включите её в ассортимент, 3120–500. Для двух неподтверждённых вариантов оставьте эти поля пустыми до получения документации.

**Магниты**

```text
Термостойкие неодимовые магниты марки N52Н
```

**Электротехническая сталь**

Высокочастотная электротехническая сталь обеспечивает минимальные электромагнитные потери

**Провод**

```text
Эмалированный высокотемпературный провод гарантирует высокий коэффициент заполнения пазов и низкое внутреннее сопротивление
```

**Подшипники**

Отечественные высокоскоростные подшипники

Прочный анодированный колокол из алюминиевого сплава, оригинальный дизайн для экономии веса и быстрого отвода тепла

```text
Вал из нержавеющей стали
```

### Ключевые особенности — по одной на строке

Это редакционно сокращённый вариант исходных тезисов, без добавления новых технических обещаний.

```text
Высокая мощность
Проверка качества при сборке
Перегрузочная способность на 20% выше аналогов
Испытания при температуре от −40 °С до +50 °С
```

Текущий шаблон также выводит заполненные материалы в списке особенностей карточки, поэтому повторять N52Н, сталь и вал в этом поле не нужно. Эти маркетинговые утверждения перенесены из прежних материалов; их испытательное обоснование в текущем комплекте не предоставлено.

### Изображения, испытания и документация

- Главное изображение выберите в стандартной панели «Изображение товара», загрузив соответствующий файл. Пути к подходящим локальным файлам приведены в карточках.
- «Изображения свайпера — порядок слайдов»: нажмите выбор из медиатеки, загрузите изображения этой модели и выберите их. У 2807 есть локальные файлы `e1-2.png`, `e1-3.png`, `e1-4.png`. Их нельзя использовать для других моделей без сверки.
- «График: тяга / ток», «График: тяга / мощность», «График: КПД / нагрузка», «График: обороты / напряжение»: оставьте пустыми до получения готовых графиков. Чертежи не являются графиками испытаний.
- «Datasheet», «Чертёж», «3D-модель STEP», «Результаты испытаний»: вставьте прямые ссылки на загруженные файлы конкретной модели. В проверенных материалах проекта готовых документов нет, ссылки не выдуманы.
