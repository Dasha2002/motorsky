# Товары MotorSky: заполнение текущей темы WordPress

Подготовлено 16 октября 2026 года по предоставленному PDF, старому сайту и фактическим полям темы 1.10.2. Это материалы для ручного переноса: сайт, тема и товары автоматически не менялись.

Для пяти моделей основным источником числовых параметров выбран PDF; для 3120–500 KV — старый сайт. Это рабочий вариант заполнения, а не подтверждение актуальности PDF: дата/редакция каталога не указаны. Все найденные расхождения перечислены в начале соответствующей карточки. До публикации согласуйте спорные значения.

## Как переносить

1. В WordPress откройте «Товары → Добавить товар» либо нужную существующую модель.
2. В файле модели поля идут в порядке групп текущего редактора. Копируйте только содержимое блоков `text`. Пояснения и надписи «оставить пустым» не вставляйте в поля.
3. Числовые поля заполняйте без единиц. Максимальный допустимый ток двигателя не подменяйте номиналом ESC или единичным измерением испытания.
4. «Размер статора» и «Серия» — разные поля. Для 3115–400 и 3115–1300 размер не выведен из названия автоматически.
5. Большой редактор основного содержимого товара сейчас не выводится шаблоном. Для видимого текста используйте «Основные характеристики: вводный текст», «Особенности», «Рекомендации» и «Применение».
6. Заполненная галерея показывает все выбранные слайды в порядке миниатюр. Изображение товара для каталога задаётся отдельно. После изменений нажмите «Обновить».
7. Пустые поля не всегда означают пустую секцию: 2807 имеет встроенные изображения/некоторые характеристики, а секция применения и особенности — типовые тексты. Проверьте предпросмотр; для двух новых вариантов текст особенностей составлен по PDF, а применения требуют отдельного согласования. Четыре типовых применения при пустом поле не являются сведениями из PDF.
8. Документы/изображения выбираются через медиатеку. Локальный путь к PDF не является ссылкой сайта. Испытания и документы видимы всегда — флажка включения больше нет. Без файлов выводится «готовится».
9. Поле «Ключевые особенности» больше не выводит списки с точками в карточках главной и каталога. Поле «Первый экран: преимущества» относится к отдельной странице товара.
10. Отметьте «Показывать товар на главной странице», если нужен вывод в двух каталогах; иначе он будет только в общем каталоге.

## Существенные ограничения источника

- В PDF не указаны допустимые максимальные токи, единица столбца «Тяга», значение первой колонки испытаний и полная методика. Эти пробелы отмечены, значения не выданы за другой параметр.
- Для 3115–400 рекомендованы 48 В / 12S, но таблица испытаний примерно при 24 В.
- Для 3115–900 указаны ESC 60А и измерение 65А; для 3115–1300 — ESC 80А и измерение 108,5А. Рекомендации по выбору ESC требуют согласования.
- Масса 3115–1300 — именно 68 г в PDF; это не перенос массы соседней модели и не исправленная нами опечатка.
- Формулировка PDF — «максимальная эксплуатационная мощность». Поле темы называется «Максимальная мощность, Вт»; при заполнении используется значение каталога, без обещания иного режима.
- Комплектующие и прежние тексты для четырёх моделей взяты из существующих материалов проекта и сверены со страницами старого сайта. Для 3115–400 / 1300 не перенесены материалы и электрические параметры 3115–900.
- Эта подготовка не строит графики КПД по неподтверждённой методике и не создаёт отсутствующие файлы STEP. Полный исходный PDF можно загрузить в медиатеку как общий каталог и результаты испытаний.
