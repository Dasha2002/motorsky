# MotorSky

Тема WordPress для сайта производителя электродвигателей. Сделана на основе исходной вёрстки: главная, каталог и страницы товаров, производство, серводвигатели, тяговые двигатели и статьи.

## Установка

Загрузите содержимое `wp-content/themes/theme/` в папку темы на хостинге с заменой файлов. Вложенную папку `theme/theme` создавать не нужно. Для установки через админку есть `motorsky-theme.zip`.

Недостающие страницы можно создать через **Внешний вид → Настройка MotorSky**. Главная назначается в **Настройки → Чтение**.

## Заполнение сайта

- **Товары** — характеристики, тексты секций, фотографии, графики и документы. Галочка «Показывать товар на главной странице» добавляет его на главную; в общем каталоге видны все опубликованные товары. Галерея сортируется перетаскиванием миниатюр.
- **Статьи** — название, полный текст, обложка и отрывок для карточки. В «Новостях» на главной показываются шесть последних публикаций. Заголовок карточки виден целиком, описание сокращается.
- **Страницы → Производство** — тексты, фотографии и фон всех шести секций. Фото открываются в галерее своей секции, миниатюры находятся снизу. Закрытие — крестиком слева сверху, Escape или нажатием на фон.
- **Страницы → Тяговые электродвигатели** — отдельные поля для текстов и изображений. Страница серводвигателей от неё не зависит.
- Остальные статические секции редактируются в `includes/`. Основной редактор товара не выводится: его описание заполняется в полях секций.

В каталоге фильтры применяются сразу, без перезагрузки. На телефоне кнопка «Показать товары» закрывает окно фильтров.

## Формы

Email получателя задаётся в **Товары → Настройки каталога**. Если поле пустое, письма уходят администратору WordPress. На хостинге проверьте доставку и настройте SMTP при необходимости. Страница политики выбирается в **Настройки → Конфиденциальность**.

## Файлы и сборка

Исходники лежат в корне проекта, готовая копия для хостинга — в `wp-content/themes/theme/`. Стили находятся в `assets/css/`, скрипты — в `assets/js/`. Если меняете готовую копию вручную, перенесите правки в исходники перед сборкой: ZIP собирается из корня.

Архив собирается командой `powershell -ExecutionPolicy Bypass -File scripts/package-theme.ps1`.

Материалы для ручного заполнения товаров находятся в `output/product-transfer/`, общий PDF — в `output/pdf/MotorSky-all-products.pdf`. Спорные характеристики отмечены в карточках моделей.
